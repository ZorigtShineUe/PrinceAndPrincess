# Шинэ жил 2027 — Ханхүү, Гүнж сонгох вэб (Shine UE School)

## Ажиллуулах

1. [Node.js](https://nodejs.org) суулгасан байх (v18+).
2. Анх удаа нэг л удаа: `npm.cmd install`
3. Серверийг асаах: **`start.bat`** файл дээр давхар дарна (эсвэл терминалд `node server.js`).
   Хар цонх нээлттэй байх хооронд сайт ажиллана — хаавал санал өгөх үед «Сервертэй холбогдож чадсангүй» гэж гарна.
   > PowerShell дээр `npm start` бичихэд «running scripts is disabled» гэж гарвал `node server.js` эсвэл `npm.cmd start` ашиглана.
4. Терминал дээр гарах хаягуудыг ашиглана:
   - **Санал өгөх хуудас** — `http://localhost:3000` (сурагчид утсаараа ижил Wi-Fi сүлжээнээс «Сүлжээнд» гэсэн хаягаар орно)
   - **Удирдлага** — `http://localhost:3000/admin` (анхдагч нууц үг: `shine2027`)
   - **Тодруулах дэлгэц (проектор)** — `http://localhost:3000/reveal`

Нууц үгийг солих (PowerShell): `$env:ADMIN_PASSWORD="шинэ-нууц-үг"; node server.js`

## Ашиглах дараалал

1. `/admin` → **Тэнхимүүд** хэсэгт сургуулийн тэнхимүүдийг нэмнэ (нэрийг ✎-ээр солих, ×-ээр устгах).
   Сурагчид санал өгөхдөө эхлээд тэнхимээ сонгоод, дараа нь тухайн тэнхимийн нэр дэвшигчээс сонгоно («‹ Буцах»-аар тэнхим рүү буцна).
   Дараа нь жишээ нэр дэвшигчдийг устгаад өөрсдийнхөө жагсаалтыг оруулна (тэнхимийг мөр бүрт жагсаалтаас сонгоно):
   - Excel-ээс **Тэнхимийн нэр | Овог | Нэр** (эсвэл эхэнд нь **Төрөл**: Ханхүү/Гүнж) баганатай мөрүүдийг хуулж буулгана, эсвэл CSV файл сонгоно.
   - Мөр бүрт «Зураг оруулах» дээр дарж зураг нэмнэ (автоматаар 5:6 харьцаагаар тайрагдана).
   - **Хадгалах** дарна.
2. Сурагчид санал өгнө — нэг браузер нэг л удаа (хүсвэл «Нэг IP хаягаас нэг санал»-ыг асаана).
3. Баяр дээр `/reveal`-ийг проектороор харуулна. Бүгд санал өгсний дараа `/admin` дээр **Тоолуур эхлүүлэх** дарна
   (анхдагч 2 минут, «Хугацаа» талбараас өөрчилнө). Тоолуур бүх утас, проектор дээр харагдаж, энэ хооронд
   санал өгч амжаагүй хүмүүс санал өгсөөр байж болно. 0:00 болоход санал хураалт автоматаар хаагдаж,
   хөшиг хаагдаад нээгдэхэд хамгийн олон санал авсан ханхүү, гүнж тайзан дээр тодорно.
   Тоолуургүйгээр шууд тодруулах бол **Шууд тодруулах** (3-2-1 тоолно).

## Санал тэнцвэл — дахин санал хураалт

1. `/admin` дээр «Санал хураалт нээлттэй»-г унтраана.
2. Тэнцсэн төрөл бүрт товч гарна: **Ханхүү: дахин санал хураах**, **Гүнж: дахин санал хураах** эсвэл **Хоёуланд нь дахин санал хураах**.
3. Шинэ шат нээгдэж, тоолуур автоматаар эхэлнэ. Сурагчдын утсан дээр зөвхөн тэнцсэн нэр дэвшигчид гарна. Хүн бүр энэ шатанд дахин нэг удаа санал өгнө.
   Тэнцээгүй төрлийн ялагч өмнөх шатных хэвээр үлдэнэ.
4. Дахиад тэнцвэл дахин шат нээж болно. Андуурч нээсэн бол **Энэ шатыг цуцлах** дарна.

Тэнцсэн хэвээр тодруулбал тэнцсэн бүх нэр дэвшигч дэлгэцэнд гарч, «санал тэнцсэн» гэсэн тэмдэглэл харагдана.

## Бүтэц

- `server.js` — Node.js сервер (нэмэлт сангүй), саналыг `data/db.json`-д хадгална
- `public/js/tree-svg.js`, `public/js/tree.js` — гацуур мод (GSAP DrawSVG, MotionPath, Physics2D). Модны дүрслэл, хөдөлгөөнийг
  [krishnachoudhary1969/Merry-Christmas](https://github.com/krishnachoudhary1969/Merry-Christmas) (MIT лиценз)-ээс авч,
  оройн одыг сургуулийн лого-оор сольсон. Лицензийн бичвэр `tree-svg.js` файлын эхэнд бий.
- `public/js/fx.js` — canvas цас, конфетти
- `public/js/app.js` — санал өгөх хуудас (мод зурагдаад 5 секундын дараа нээгдэнэ)
- `public/js/admin.js`, `public/js/reveal.js` — удирдлага, тодруулах дэлгэц
